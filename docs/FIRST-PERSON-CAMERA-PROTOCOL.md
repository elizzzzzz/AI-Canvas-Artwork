# 第一人称摄影协议

本项目所有镜头都必须是当集第一人称主人公的主观视角。镜头可以运动，但镜头不能脱离主人公的知觉、行动路径和信息来源。

## 允许的机位

### 运动相机

镜头位于主人公的眼高、胸前或手持位置，适合奔跑、追车、入城、穿廊和现场核验。画面可以出现主人公的手、袖口、道具或身体边缘，但不能出现完整的第三人称身体展示。

### 隐形自拍杆

镜头位于主人公近身位置，适合查看军报、封泥、云令匣、药包和状纸。自拍杆本身不可见，视线移动必须由主人公的手部动作、转头或道具反应解释。

### 近距离跟随无人机

镜头作为主人公的主观跟随视角，在主人公前进、追车、入城或观察群体时低速移动。无人机不能飞到主人公无法看到、听到或获知的地点；它只扩展主人公的运动视线，不提供上帝视角。

## 禁止的镜头

- 传统第三人称正反打；
- 切到主人公不在场的宫殿、行宫或府邸内部；
- 没有口述、密报或回报来源的异地插叙；
- 从空中展示主人公完整身体的上帝视角；
- 用俯拍直接展示主人公无法看到的全局；
- 通过画面展示太子、誉王或北燕六皇子当下反应，而主人公没有亲临现场。

## 不在场信息的处理

主人公没有亲临的场景必须改成以下方式之一：

1. 信使在主人公面前回报；
2. 密报递到主人公手中，由主人公阅读或听人念出；
3. 云令传讯通过灯号、木牌或口头回执传到主人公所在地点；
4. 主人公根据已收到的消息做出推断，但画面不展示被推断对象的现场。

## 灰模验收

每个镜头都要回答：

- 摄影机是否处于主人公的眼高、胸前、手持或主观跟随路径；
- 主人公是否能看到、听到或已被告知画面信息；
- 如果主人公不在场，画面是否只展示回报者和信息载体；
- 机位运动是否服务于主人公的任务，而不是展示场景本身；
- 口播集合是否使用主人公主观跟随视角，而不是切成第三人称合影。
