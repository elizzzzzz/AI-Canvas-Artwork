# 灰模评审表

## 评审对象

- 第一集《梅岭旧令》；
- 第二集《麒麟锦囊》；
- 第三集《入京》；
- 评审版本：9:16 低精度角色和场景体块；
- 评审目标：决定是否进入参考图批量生成和视频试跑。

## 镜头级检查

每个镜头按 1–5 分记录：

- 主观机位是否清楚；
- 主人公是否能看到、听到或已获知画面信息；
- 主任务是否明确；
- 支线故障是否具体；
- 主人公是否实际暂停主任务救火；
- 云令能力是否通过行动出现；
- 角色和道具是否保持连续；
- 竖屏构图是否拥挤；
- 声音和口述是否补足不在场信息；
- 口播集合是否可执行。

## 阻塞级别

- P0：违反第一人称协议、出现无来源异地现场、主任务无法理解或镜头无法完成；
- P1：人物站位、道具连续性、信息来源或时长明显影响理解；
- P2：构图、节奏、声音或表演可以在最终渲染前修正；
- P3：纯美术细节或偏好，不阻塞下一阶段。

## 放行条件

以 [强制3D规范](MANDATORY-3D-PRODUCTION.md) 为准，几何问题不能用平均评分或修复计划代替修复完成：

- 每个即将生成的图片/片段有可打开的完整3D场景包与对应相机，实际比例、遮挡、人物位置/朝向、道具支撑/接触和机构均已检查。
- 任何第一人称违规、非预期穿插、错误关节、接触/支撑错误和关键证据不可见都阻塞，修复并复查后才能签核。
- 3D证据与当前模型、源脚本和机位版本哈希一致；有明确人工评审人及时间。
- 视频按目标帧率检查全部画面及结束边界，关键接触增加采样/连续约束；不是只查首尾帧。
- 7个主场景及子空间纳入清单；配角、手、车辆、马、道具都不能遗漏。
- 分集时长仍为150/155/165秒；口播人物聚齐且镜头前口型无遮挡，主人公从镜后参与。
- `geometry_preflight.py --scope <exact_scope>` 返回0；艺术审核与当前费用批准同时有效。
- 当前92个范围均未完成完整审批，首批8图只作候选；P01局部灰模不等于完整镜头通过。
