# 灰模评审表

## 评审对象

- 第一集《梅岭旧令》；
- 第二集《麒麟锦囊》；
- 第三集《入京》；
- 评审版本：9:16 低精度角色和场景体块；
- 评审目标：决定是否进入参考图批量生成和视频试跑。

## 镜头级检查

每个镜头按 1–5 分记录：

- 主观机位是否清楚；
- 主人公是否能看到、听到或已获知画面信息；
- 主任务是否明确；
- 支线故障是否具体；
- 主人公是否实际暂停主任务救火；
- 云令能力是否通过行动出现；
- 角色和道具是否保持连续；
- 竖屏构图是否拥挤；
- 声音和口述是否补足不在场信息；
- 口播集合是否可执行。

## 阻塞级别

- P0：违反第一人称协议、出现无来源异地现场、主任务无法理解或镜头无法完成；
- P1：人物站位、道具连续性、信息来源或时长明显影响理解；
- P2：构图、节奏、声音或表演可以在最终渲染前修正；
- P3：纯美术细节或偏好，不阻塞下一阶段。

## 放行条件

进入参考图批量生成前必须满足：

- 三集没有 P0；
- P1 已有明确修复方案和对应镜头；
- 三集主观镜头数量分别为 11、11、12；
- 三集时长分别为 150、155、165 秒；
- 五位主要人物可以通过角色锚点区分；
- 六类核心场景可以通过场景锚点区分；
- 结尾口播在灰模中完整可见、可听；
- 内部评审人能复述每集主任务和下一集悬念。
