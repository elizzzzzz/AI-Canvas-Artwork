# 图片与视频模型基准测试

## 测试目的

使用同一场景和同一套模型无关提示词，比较实时可用模型在本项目第一人称古装短剧上的稳定性。测试只用于选型，不代表最终成片质量。

| GPT Image 2.5 Flare | 9:16 | 1K | 186 | 558 | 细节和写实质感 |

## 首轮测试数量

- 每个图片模型生成 3 张同提示词图片；
- 每个视频模型生成 1 条同提示词视频；
- 图片合计：12 张；
- 视频合计：3 条；
- 初始估算总成本：图片 1167 积分 + 视频 1421 积分 = 约 2588 积分；
- 实际扣费以平台结算为准。

## 提交前检查

- 图片模型的 9:16、分辨率和 `text_to_image` 均来自实时模型列表；
- 视频模型的 9:16、分辨率、合法时长和 `text_to_video` 均来自实时模型列表；
- 当前基准不使用参考图，因此不触发参考素材审核库；
- 每次生成 1 张图片或 1 条视频，结果单独记录；
- 任务提交前说明团队账户扣费、无法中止和预估积分，并等待用户确认；
- 图片和视频结果完成后按统一评价维度打分，再选出项目主模型和备选模型。

## 选择规则

图片模型优先级：

1. 第一人称构图和道具可读性；
2. 梅长苏／林殊角色锚点的可重复性；
3. 写实古装材质和低饱和光线；
4. 3 张图之间的稳定性；
5. 单张成本。

视频模型优先级：

1. 第一人称机位保持度；
2. 手部、袖口、药箱和军报的动作连续性；
3. 单一动作的完成度；
4. 是否出现第三人称切镜或无来源场景；
5. 时长和成本。
