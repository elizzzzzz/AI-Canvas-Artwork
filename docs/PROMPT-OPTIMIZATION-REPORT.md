# 基准分镜提示词优化报告

- 日期：2026-10-24
- 模式：快速优化 + 生成前静态审查
- 目标：提高不同视频模型对第一人称机位、动作顺序和关键道具的遵循度
- 实测状态：尚未生成；以下是静态修改和待验证指标，不代表已提升成功率

## 原提示词的主要问题

1. 图片提示词同时要求“第一人称”和“no selfie stick”，与项目允许的隐形自拍杆机位存在冲突；
2. 视频提示词只有动作描述，没有明确的起始状态、动作阶段和结束状态；
3. “无第三人称、无航拍、无切镜”虽有约束，但没有把镜头拥有者、机位载体和动作路径放在同一结构中；
4. 图片和视频共同使用一段文字，没有区分静态画面约束和时间动作约束；
5. 参考图、道具状态和跨镜连续性没有单独成为可检查字段。

## 已采用的最小修改

- 增加 `SINGLE IMAGE` 和 `ONE CONTINUOUS SHOT`，减少模型自行切镜的空间；
- 明确 `POV owner` 和 `camera rig`，把运动相机与隐形自拍杆作为允许的机位；
- 将视频提示词拆成 `Start state → Beat 1 → Beat 2 → Beat 3 → End state`；
- 保留“手、袖口、药箱、军报、残旗”五个可观测锚点；
- 明确禁止露脸、完整身体、第三人称和异地换景；
- 将模型迁移规则拆开，避免把 Seedance 的格式硬套到 Kling 或 MiniMax。

## 待验证指标

每个图片模型 3 次试验、每个视频模型 1 次首轮试验后，按 1–5 分记录：

- POV 遵循度；
- 手部和袖口稳定度；
- 药箱、军报、残旗可读度；
- 动作顺序完成度；
- 是否发生切镜或异地场景跳转；
- 运动稳定度；
- 重抽时只修改一个变量的可修复性。

只有看到实际输出后，才能判断哪种模型和提示词组合更适合本项目。
