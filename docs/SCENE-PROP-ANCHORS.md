# 场景与关键道具锚点

## 统一摄影规则

- 画幅：9:16；
- 竖屏安全区：人物眼睛、关键道具和口播口型必须避开上下 12% 边缘；
- 主要镜头：35mm、50mm、70mm；战场和城门可用 24mm；
- 写实材质：木、纸、铁、湿石、旧皮、布和蜡封；
- 禁止：现代灯具、现代文字、现代塑料、现代道路标线和现代 UI。
- 所有镜头为主人公主观视角，允许运动相机、隐形自拍杆和近距离跟随无人机；禁止第三人称正反打和主人公不在场的异地切镜。

## 梅岭战场

- 空间：雪原、低矮残坡、折断军械和远处火线；
- 主光：冷蓝月光从画面左后方进入，暗红火光作为轮廓光；
- 构图：林殊居中或偏下，残旗从上方压入，制造战场压力；
- 声音：风雪、远鼓、旗面撕裂、铁器撞击；
- 关键道具：军符、染血军报、赤焰残旗。

## 江左盟旧档室

- 空间：高柜、窄窗、长案、木匣和索引牌；
- 主光：窄窗冷光加案头暖烛，形成资料检索的明暗层次；
- 构图：档案柜形成竖向线条，适配 9:16；
- 声音：木柜滑轨、纸张翻动、封泥碎裂；
- 关键道具：半枚旧令、原卷、备用存卷、封签。

## 琅琊阁外院与分舵

- 空间：雨廊、木桥、层叠书楼、信匣台和密道入口；
- 主光：雨天散射光，封泥和灯号使用少量暖色；
- 构图：用长廊透视线引导谢听云行动；
- 声音：檐雨、木屐、木牌落桌、铜片碰撞；
- 关键道具：麒麟锦囊、三色封泥、木质云令匣、路线图。

## 北燕行宫

- 空间：旧墙、空置宫灯、简陋案台、风雪透窗；
- 主光：冷白窗光，六皇子脸部保留一小块稳定暖光；
- 构图：让空旷背景包围六皇子，体现势弱而有秩序；
- 声音：风撞窗、远马嘶、衣料摩擦；
- 关键道具：未拆锦囊、旧地图、空宫灯。

## 入京路途

- 空间：雨棚、泥路、车厢、药箱、断轴和临时封存桌；
- 主光：灰绿雨天，故障恢复后加入稳定暖光；
- 构图：近景表现资源故障，俯拍表现状纸、药包、路线图重新归位；
- 声音：车轮、雨滴、木轴断裂、药瓶碰撞、封蜡；
- 关键道具：湿损状纸、药包、路线图、车轴、云令匣。

## 金陵城门

- 空间：高城墙、朱门、湿石板、门内宫灯和少量人流；
- 主光：门外灰绿，门内暗金和朱红；
- 构图：城门作为纵向框景，人物由门外进入门内；
- 声音：城门开启、钟声、雨声减弱、远处人声；
- 关键道具：带“燕”字的密报、入京文牒、侯府印记。
