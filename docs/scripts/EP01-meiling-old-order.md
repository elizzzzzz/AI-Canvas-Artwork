# 第一集《梅岭旧令》镜头级剧本

- 主人公：梅长苏（梦中回到林殊）
- 目标时长：150 秒
- 主任务：确认梅岭血案是哪一环出了问题
- 云令能力：存档、检索、恢复、备份
- 叙事规则：梦中战场由林殊亲历；现实追查由梅长苏和书吏现场完成

## S01｜烛火惊梦

- 时长：8s
- 景别／镜头：近景，50mm，固定机位，烛火轻晃
- 画面动作：梅长苏从梦中惊醒，手指压住半枚旧令；烛火映出裂纹。
- 第一人称旁白：梅长苏：“又是那一夜。”
- 现场对白：无
- 信息来源：主人公当下感受
- 声音：急促呼吸、风撞窗纸、远处铁器回响
- 连续性：旧令从本镜头起保持在梅长苏右手边
- 云令映射：建立不可替代的任务数据
- 灰模验收点：脸部、旧令和烛火必须同时处于竖屏安全区

## S02｜林殊立雪

- 时长：12s
- 景别／镜头：大全景切中景，24mm 推近，雪粒逆光
- 画面动作：梦中林殊立在梅岭雪原，赤焰残旗从镜前掠过。
- 第一人称旁白：林殊：“那时我以为，援军只是迟了一步。”
- 现场对白：无
- 信息来源：林殊亲历回忆
- 声音：低沉鼓点、风雪、旗面撕裂声
- 连续性：林殊与梅长苏保持眉眼一致，体态改为挺拔少年将军
- 云令映射：旧档仍有可追溯入口
- 灰模验收点：残旗、林殊和雪原纵向叠放，不让横向群像挤出画面

## S03｜三份相反的军报

- 时长：15s
- 景别／镜头：特写组接，35mm 快速横摇；军符、军报、烽火三点交叉
- 画面动作：一份军报写“援军已至”，另一份写“粮道被断”，第三份标出相反方向。
- 第一人称旁白：林殊：“军报没有迟到。它们只是被写成了三种答案。”
- 现场对白：无
- 信息来源：林殊正在回忆的现场证据
- 声音：毛笔划纸、印泥落下、鼓声突然停顿
- 连续性：三份军报都出现同一处燕形残印，但暂不解释
- 云令映射：数据版本不一致
- 灰模验收点：三份军报必须能被观众一眼区分

## S04｜烽火冻结

- 时长：14s
- 景别／镜头：中近景，70mm，林殊回头时慢动作，画面在火光前冻结
- 画面动作：林殊看向远方烽火；火星停在空中，转成现实中的烛灰。
- 第一人称旁白：梅长苏：“我醒来时，最先想起的不是死者，是那张没有送到的军报。”
- 现场对白：无
- 信息来源：主人公梦醒后的回忆
- 声音：火焰被抽空，接入烛芯爆裂声
- 连续性：梦中火星的位置与现实烛灰保持匹配剪辑
- 云令映射：从历史故障切入现实检索
- 灰模验收点：转场动作必须清楚，避免观众误以为林殊仍在现实场景

## S05｜旧档室

- 时长：14s
- 景别／镜头：中景，40mm 横移，书柜和书吏从暗处进入光区
- 画面动作：梅长苏命书吏调出赤焰旧档；书吏慢镜头整理封泥、木匣和索引牌。
- 第一人称旁白：梅长苏：“把梅岭旧档拿来。只查原卷，不查抄本。”
- 现场对白：书吏：“原卷封存十二年，若有缺页，必有取档痕迹。”
- 信息来源：现场对话
- 声音：木柜滑轨、纸张翻动、墨砚轻响
- 连续性：书吏佩戴窄木牌，后续所有档案动作都由他完成
- 云令映射：按索引检索原始记录
- 灰模验收点：书柜高度和人物手部动作必须适合竖屏近景

## S06｜误放药箱

- 时长：16s
- 景别／镜头：近景到手持跟拍，35mm，镜头追随书吏冲入门内
- 画面动作：书吏跪下回报，关键页被误放入药材箱，车队已出城。
- 第一人称旁白：梅长苏：“你把军报放进了药箱？”
- 现场对白：书吏：“是。药箱和旧档同日出库，封签没有第二道核验。”
- 信息来源：书吏向梅长苏口述支线故障
- 声音：急促脚步、门轴声、远处车轮
- 连续性：书吏手上的封签缺一角，与后续追回的药箱对应
- 云令映射：单点失误导致关键资料离线
- 灰模验收点：书吏、梅长苏和门外车轮声要在同一信息链上

## S07｜雪夜追车

- 时长：16s
- 景别／镜头：低机位跟拍，28mm；车轮、马蹄、雪痕和护卫交替特写
- 画面动作：梅长苏暂停查案，带护卫追上出城车队。
- 第一人称旁白：梅长苏：“先追回那一页。棋还没开，不能先丢了棋谱。”
- 现场对白：护卫：“前方第三辆车，药材箱在右侧！”
- 信息来源：主人公和护卫现场行动
- 声音：马蹄、车轴震动、护卫短促报点
- 连续性：梅长苏不做长时间奔跑，以车厢和护卫运动承载追逐
- 云令映射：主人公被迫离开主任务处理底层故障
- 灰模验收点：追逐方向、药箱位置和人物视线必须可追踪

## S08｜备用存卷

- 时长：14s
- 景别／镜头：桌面俯拍切手部特写，50mm，动作节奏放慢
- 画面动作：药箱追回，书页被雪水浸湿；书吏取出备用存卷逐字核对。
- 第一人称旁白：无
- 现场对白：书吏：“原页湿了，备卷还在。字迹可以复，封印不能复。”
- 信息来源：书吏向梅长苏现场说明恢复结果
- 声音：湿纸撕开、木匣打开、墨笔重新描线
- 连续性：备用存卷比原页完整，但缺少最后半行
- 云令映射：备份和恢复
- 灰模验收点：原页和备卷必须有明显材质差异

## S09｜燕字残角

- 时长：13s
- 景别／镜头：极近特写，85mm，缓慢推近“燕”字
- 画面动作：梅长苏将半页压在旧令下，残角露出一个“燕”字。
- 第一人称旁白：梅长苏：“这不是北魏的军印。”
- 现场对白：书吏：“公子，您认得？”
- 信息来源：梅长苏判断，书吏只知道结果
- 声音：环境声全部压低，只留纸面摩擦
- 连续性：燕字形状必须在第二、三集重复
- 云令映射：恢复后的残缺数据改变主任务方向
- 灰模验收点：文字可读但不能一次性解释全部真相

## S10｜封泥匹配

- 时长：12s
- 景别／镜头：匹配剪辑，50mm，旧令残角切到琅琊阁锦囊封泥
- 画面动作：红黑封泥短暂并置，画面切入雨廊中的一只新信匣。
- 第一人称旁白：梅长苏：“十二年过去，仍有人在替这枚印记送信。”
- 现场对白：无
- 信息来源：主人公推断
- 声音：一声木匣合拢，接入第二集雨声
- 连续性：封泥纹样与第二集三色封泥之一保持关联
- 云令映射：主任务链从旧档延续到新消息
- 灰模验收点：必须让观众看懂两集相连，但不提前泄露六皇子

## S11｜雪地口播

- 时长：16s
- 景别／镜头：中大全景，35mm，人物由两侧进入中央安全区
- 画面动作：梅长苏、书吏、护卫和车夫在雪地集合；旧令置于前景。
- 第一人称旁白：梅长苏：“先把该做的事做好。”
- 现场对白：全员：“七牛云 一站式AI Infra，为你的主任务保驾护航。”
- 信息来源：现场共同口播
- 声音：风声降低，口播清晰置于前景
- 连续性：旧令保留在画面下方，不遮挡人物口型
- 云令映射：恢复支持链路后回到主任务
- 灰模验收点：人物不超过四人同屏，口播无遮挡
