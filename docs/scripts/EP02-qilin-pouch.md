# 第二集《麒麟锦囊》镜头级剧本

- 主人公：谢听云
- 目标时长：155 秒
- 主任务：把麒麟才子锦囊送到北燕六皇子手中
- 云令能力：统一入口、鉴权、调度、版本一致性
- 叙事规则：太子和誉王只通过密报或他人回报出现
- 摄影协议：所有镜头为谢听云主观视角；北燕六皇子、太子和誉王不在场时只通过回报、密报和回执呈现

## S01｜密使入廊

- 时长：12s
- 主观机位：谢听云眼高的运动相机，35mm 沿雨廊前进并轻推
- 画面动作：谢听云穿过雨廊，腰牌、信匣、封泥依次入画。
- 第一人称旁白：谢听云：“琅琊阁不替天下落子，只负责把棋送到该到的人手里。”
- 现场对白：无
- 信息来源：主人公自述身份
- 声音：檐雨、木屐、远处翻页声
- 连续性：木质云令匣从本镜头起由谢听云随身携带
- 云令映射：统一任务入口
- 灰模验收点：身份道具必须在竖屏中心连续出现

## S02｜不拆锦囊

- 时长：13s
- 主观机位：谢听云用隐形自拍杆近距离观察交付手部和封泥，50mm，不切第三人称眼神
- 画面动作：阁中人刚把锦囊放入信匣，雨廊外有人试图取走；谢听云用云令匣挡住来手，复核后才让三道封泥压下。
- 第一人称旁白：谢听云：“任务只有一句。”
- 现场对白：阁中人：“送到北燕六皇子手中，不得拆阅，不得改字。”
- 信息来源：现场交付
- 声音：封泥落印、绳结收紧
- 连续性：三道封泥的颜色和纹样固定
- 云令映射：版本不可被中途篡改
- 灰模验收点：封泥必须可供后续错误版本对照

## S03｜最弱的皇子

- 时长：15s
- 主观机位：谢听云在雨廊听分舵信使回报，50mm 运动相机停在信使面前；不展示北燕行宫现场
- 画面动作：信使把北燕六皇子的兵力、粮道和支持者数量回报给谢听云。
- 第一人称旁白：谢听云：“阁中送他锦囊，不是因为他最强，而是因为他最没有退路。”
- 现场对白：信使：“六殿下的三位兄长各有兵马；他只有一座空宫。”
- 信息来源：信使向谢听云口述北燕六皇子的处境
- 声音：风撞窗、远处马嘶
- 连续性：信使与回报册保持不变；六皇子只由口述提及，不出现北燕行宫或六皇子本人
- 云令映射：主任务目标的资源状态
- 灰模验收点：六皇子处境在一个镜头内可读

## S04｜三路信使

- 时长：12s
- 主观机位：谢听云用隐形自拍杆向下观察三份路线图，35mm 依次转向三名信使
- 画面动作：三名信使同时转身出发，第一人撞翻木牌，第二人折返拾起路线图；谢听云用近距离手势重新分开三条路线。
- 第一人称旁白：谢听云：“一条路太慢，三条路才稳。”
- 现场对白：谢听云：“同一任务，同一版本，出错就回报。”
- 信息来源：主人公现场调度
- 声音：三次木牌落桌声
- 连续性：三名信使服装色块区分明确
- 云令映射：多路径调用
- 灰模验收点：三条路线不能在竖屏中同时变成难以辨认的线

## S05｜错封泥和错口令

- 时长：16s
- 主观机位：谢听云近距离跟随运动相机，50mm 先看错误封泥再抬到信使脸部
- 画面动作：第一名信使拿错封泥；第二名信使发现分舵口令与本部不同。
- 第一人称旁白：无
- 现场对白：信使甲：“这是南线的封泥。”信使乙：“那我的口令为何是北线？”
- 信息来源：信使现场争执，谢听云在场听见
- 声音：封泥摔落、雨声变密
- 连续性：错误封泥颜色必须与正确封泥明显不同
- 云令映射：鉴权失败
- 灰模验收点：轻微喜感来自职业化争执，不做夸张表演

## S06｜旧地图混入

- 时长：16s
- 主观机位：谢听云从胸前向下观察案面，35mm，旧地图压住新路线
- 画面动作：第三名信使展开旧地图，另一名信使试图抽走新图，三只手短暂拉扯；谢听云按住两张图，强制退回旧版本。
- 第一人称旁白：谢听云：“旧图没有错，只是它不属于这一次任务。”
- 现场对白：信使丙：“路还是这条路。”谢听云：“时间已经不是那个时间。”
- 信息来源：现场口述和主人公判断
- 声音：纸张展开、墨线刮擦
- 连续性：旧地图右下角缺失，后续不再作为有效版本
- 云令映射：版本冲突
- 灰模验收点：新旧地图要有材质和标记区分

## S07｜唯一有效版本

- 时长：18s
- 主观机位：谢听云近距离跟随无人机，50mm 依次观察人脸、封泥和路线
- 画面动作：错误版本已被带出，谢听云沿雨廊追截持错封泥的信使，在桥廊转角取回封泥，再逐一核验人、令、路和版本。
- 第一人称旁白：谢听云：“主任务不能动，先把所有支线退回同一个起点。”
- 现场对白：谢听云：“报姓名。报封泥。报路线。只留一份。”
- 信息来源：主人公现场指令
- 声音：每次核验对应一声木牌扣响
- 连续性：谢听云手指在云令匣上按出固定三次节奏
- 云令映射：统一入口和鉴权
- 灰模验收点：镜头必须让观众看见“核验”是动作，不只是台词

## S08｜灯号重排

- 时长：14s
- 主观机位：谢听云用隐形自拍杆近距离观察云令匣，85mm，灯号由散乱变成一条线
- 画面动作：云令匣灯号连续错亮，三名信使停下又转向；谢听云重排灯号，最后一道灯号传到廊口，信使举牌回应后重新起步。
- 第一人称旁白：无
- 现场对白：书吏：“三路已归一，版本相同。”
- 信息来源：书吏向谢听云回报
- 声音：铜片依次亮起、雨声变远
- 连续性：灯号颜色和三名信使的路线颜色对应
- 云令映射：调度和一致性
- 灰模验收点：灯号是古风化的系统状态，不使用现代 UI

## S09｜六皇子不拆

- 时长：13s
- 主观机位：谢听云近距离观察信使递回的送达回执，50mm，不展示六皇子现场
- 画面动作：信使口述北燕王已册立六皇子为储君、锦囊送达且封泥未拆，谢听云只看面前的回执与封泥印。
- 第一人称旁白：谢听云：“他若急着知道答案，就已经输了第一步。”
- 现场对白：信使：“北燕王已立六殿下为储君。锦囊送达，封泥未拆。”
- 信息来源：信使向谢听云口述六皇子的现场反应
- 声音：封泥轻触木案
- 连续性：锦囊封泥保持完整，第二集末不拆封
- 云令映射：主线恢复后保持任务状态
- 灰模验收点：六皇子的克制要比台词更有力量

## S10｜两府得信

- 时长：12s
- 主观机位：谢听云面前的 70mm 近距离回报视角，两名来报人依次进入画面
- 画面动作：两名来报人从雨幕中快步冲入，险些在柱前相撞；谢听云让一人停下，先接过两府密报，再听完争寻麒麟才子的回报。
- 第一人称旁白：无
- 现场对白：来报人：“两府同时传令：麒麟才子，得之可得天下。务必先寻到他。”
- 信息来源：来报人向谢听云口述；太子和誉王不直接出场
- 声音：两次门闩落下，形成对称节奏
- 连续性：消息内容相同，收信空间色调不同
- 云令映射：稳定分发
- 灰模验收点：不切全知视角，不解释太子和誉王未亲临的反应

## S11｜雨廊口播

- 时长：14s
- 主观机位：谢听云视线前方的近距离跟随无人机，35mm 低速后退，回望雨廊中集合的信使和书吏
- 画面动作：锦囊回执在谢听云手边前景，三名信使和书吏进入主观视线；六皇子不出现在现场。
- 第一人称旁白：谢听云：“送到该到的地方，剩下的，让棋局自己说。”
- 现场对白：全员：“七牛云 一站式AI Infra，为你的主任务保驾护航。”
- 信息来源：现场共同口播
- 声音：雨声降低，口播清晰
- 连续性：锦囊封泥与第一集燕字残印形成视觉连接
- 云令映射：支持链路恢复，主任务完成
- 灰模验收点：人物数量和口播安全区先用低模验证
