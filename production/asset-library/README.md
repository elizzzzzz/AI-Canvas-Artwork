# 三维代理资产库 v1

本目录保存项目中可复用的真实 GLB 代理模型、预览图和镜头装配索引。它服务于比例、遮挡、朝向、支撑关系、道具状态和第一人称摄影机的前置检查。

当前版本包含 100 个独立模型：

| 类别 | 数量 |
|---|---:|
| 人物 | 16 |
| 手部 | 6 |
| 动物 | 1 |
| 服装装备 | 11 |
| 道具 | 31 |
| 车马组件 | 8 |
| 建筑家具 | 18 |
| 道路环境 | 9 |

## 文件

- `catalog-v1.json`：稳定 ID、类别、尺寸、场景关联、模型哈希和限制说明。
- `shot-asset-map-v1.json`：34 个逻辑镜头、67 个片段的资产装配计划。
- `models/*.glb`：实际导出的层级网格。每个模型可以独立下载或装配。
- `previews/*.png`：资产预览图。
- `scenes/P01-assembly-v1.*`：药箱、军报、旧令、双手、案面和主观相机的 P01 组合草模。
- `viewer.html`：无需外部依赖的本地 WebGL2 查看器，可筛选资产、切换正/侧/顶视，并调整药箱开盖角度。
- `library-overview-v1.jpg`、`all-assets-atlas-v1.jpg`：索引审阅图。

运行查看器：

```bash
python3 -m http.server 8767 --bind 127.0.0.1 --directory production/asset-library
```

然后打开 `http://127.0.0.1:8767/viewer.html`。

## 几何约定

模型作者坐标使用米制、`+Z` 向上、`+Y` 为局部前方。GLB 根节点写入从作者坐标到 glTF 坐标的转换。每个模型保留层级节点；手部有 5 个手指根节点，马匹有 4 个腿根节点，药箱盖有固定的后沿铰链根节点。药箱默认开盖角度为 100°，同一模型支持开合状态。

## 使用政策

镜头中可见的实体先登记稳定资产 ID，再在场景文件中创建明确实例。人物的手和袖口按第一人称机位单独建模；主人公的脸、头、肩背不作为成片中的第三人称画面出现。衣物和装备既可作为角色整体代理的一部分，也可作为独立组件使用，不能在装配时无意重复叠加。

雪、雨、火光和雾等连续场景效果通过场景效果记录，不为每个粒子创建资产。画外口述中提到但没有进入当前镜头的角色不强行加入场景。替代组件和未分配组件保留在目录中，并明确标记用途范围。

## 状态边界

这些是实际网格，但仍是低精度代理：没有最终雕刻、精确面容、蒙皮、完整动画骨骼或逐镜头接触解算。马匹步态、手与道具接触、遮挡、相机路径和视频全帧连续性必须在对应场景包中继续检查。`production_approval` 当前全部为 `false`；资产目录、预览图和 P01 组合草模都不能单独放行图片或视频生成。

资产被纳入 `production/geometry/coverage-v1.json` 后，每个 `LIB:<ID>` 范围仍需完整的模型、场景、相机、预览、深度、物体 ID、实际报告和人工签核。生成前必须运行：

```bash
python3 tools/geometry_preflight.py --scope LIB:PR-CHEST
```

预检失败是当前预期状态，表示资产尚未完成场景级验收。
