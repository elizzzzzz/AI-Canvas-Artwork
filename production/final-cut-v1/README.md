# 导演版连续性预演 v1

这是面向成片目标的三章式灰模连续性预演，使用现有逐帧运动证据和文字章节卡组装，不调用图片或视频生成服务。

文件：

- `qiniu-langya-continuity-preview-v1.mp4`：540×960、24fps、约 32 秒；
- `cards/`：三集章节卡和结尾品牌卡；
- `segments/`：按故事顺序组织的灰模动作片段；
- `concat.txt`：可重建的拼接清单。

故事顺序：

1. 第一集：梅岭战争/旧案异常 → 雪夜追车 → 燕字残角；
2. 第二集：锦囊执行 → 信使冲突 → 灯号调度；
3. 第三集：雨棚救援 → 车轴失控 → 城门冲入；
4. 结尾：七牛云一站式 AI Infra 的文字收束。

这条预演用于检查观众是否理解主任务、动作因果、支线故障、证据变化和三集钩子。它不是最终 AI 成片，也不能替代 3D 逐镜头批准。

重建：

```bash
python3 tools/build_continuity_preview.py
```
