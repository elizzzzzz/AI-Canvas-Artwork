# 动作片段运动草稿 v1

本目录保存 42 个动作片段的第一人称运动规划草稿，覆盖三集动作版分镜的全部动作片段。每个片段使用 24fps、明确的持续时间和结束边界，绑定到已导出的七个场景静态模型、主观相机、深度图和物体 ID 图。

当前内容包括：

- `manifest-v1.json`：42 个动作片段的运动 profile、第一人称相机路径、动作实体、接触/碰撞检查点、采样帧数量和证据哈希。
- `motion-overview-v1.jpg`：全部动作片段的审阅索引。

这些是运动规划草稿，不是逐帧渲染证据。相机路径是用于讨论的可重复草稿；人物、马匹、车轮、手部和道具尚未完成动画、碰撞求解、逐帧深度/ID 输出或人工签核。所有片段仍阻塞图片和视频生成。

## 审核重点

1. 核对主人公眼高、运动相机/隐形自拍杆/近距离跟随装置是否始终与主人公知觉共位。
2. 核对追车、马匹、车轮、断轴、门洞、桌面和人物之间的净空与支撑。
3. 核对手部交接、药箱铰链、纸张接触、封泥转移和路线上障碍物。
4. 按 24fps 检查全部帧、结束边界和自适应接触点；不能只看起始帧和结束帧。
5. 通过后再为相应 `EPxx-Sxx-yy` 范围建立正式报告和人工签核。

## 审核入口

- GitHub：PR #4 的动作版分镜与场景草模差异。
- 本地：`production/scene-blockouts/` 下的 `*-pov.png`、`*-diagnostic.png`、深度和物体 ID 文件。
- AI Canvas：制作画布中的“动作版分镜 50%+（待3D运动审核）”节点；该节点只保存说明，当前没有活动生成任务。
