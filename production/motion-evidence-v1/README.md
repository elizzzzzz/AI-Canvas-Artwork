# 高风险动作逐帧灰模证据 v1

本目录保存九个高风险动作片段的本地 24fps 灰模逐帧预演：

- `EP01-S07-01`：雪夜追车，193 帧；
- `EP02-S07-01`：雨廊追截，217 帧；
- `EP03-S05-01`：车轴失控，145 帧。

每段包含：

- `frames/`：竖屏 RGB 灰模帧；
- `depth-mm/`：同一机位的 16 位毫米深度帧；
- `object-ids/`：同一机位的 RGB 物体 ID 帧；
- `object-id-maps/`：帧对应的物体 ID 标签；
- `manifest.json`：24fps 帧顺序、时间、文件哈希和检查点。

这些证据由低精度代理模型和程序化变换生成，用于检查第一人称相机路径、实体可见性、支撑关系和动作连续性。它们没有物理碰撞求解、角色动画骨骼、马匹步态或最终材质，也没有人工签核。三段状态均为 `rendered_motion_draft_pending_human_review`，不能放行图片或视频生成。

审核重点：追车中的车轮/车体/马匹净空，雨廊追截中的人物间距和封泥交接，车轴失控中的车体倾斜、车轮接地、断轴和状纸保护。人工审核通过后仍需建立正式范围报告，不能直接把本草稿改为 `approved`。
